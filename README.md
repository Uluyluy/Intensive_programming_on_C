# 🚀 Intensive Programming on C

Этот репозиторий содержит решения учебных задач и проекты, выполненные в рамках двухнедельного интенсивного курса по программированию на языке **C**.

## 📂 Структура проекта

Репозиторий разбит на тематические модули. Каждый модуль находится в отдельной папке:

### 1. `1_Basic_c_syntax`
Основы синтаксиса языка C.
- Работа с арифметикой, типами данных (`float`, `int`).
- Базовые математические функции (`math.h`).
- Простые условные конструкции и ввод/вывод.

### 2. `2_Basic_algorithms`
Реализация классических алгоритмов без использования стандартных библиотек сортировки или поиска.
- Алгоритмы поиска наибольшео простого делителя.
- Рекурсия (числа Фибоначчи).

### 3. `3_Console_ping-pong_game`
Интерактивная консольная игра "Пинг-понг". Этот код написан максимально простыми конструкциями, чтобы новички могли в нем разобраться.
- Обработка ввода с клавиатуры в реальном времени.
- Логика движения мяча и ракеток.
- Отрисовка игрового поля в терминале.

### 4. `4_Pointers`
Глубокое погружение в работу с указателями.
- Арифметика указателей.
- Работа со статической памятью.

### 5. `5_Dynamic_memory`
Работа с кучей (Heap).
- Создание и управление динамическими матрицами.
- Корректное освобождение памяти (предотвращение утечек).

### 6. `6_Multi-file_projects_and_macroses`
Архитектура крупных проектов на C.
- Разделение кода на заголовочные (`.h`) и исходные (`.c`) файлы.
- Использование препроцессора и макросов.
- Сборка проектов через **Makefile**.

### 7. `7_Game_of_life`
Клеточный автомат "Игра «Жизнь»" Джона Конвея.
- Логика подсчета соседей (включая тороидальное поле).
- Обновление состояний поколений.
- Оптимизация работы с двумерными динамическими массивами.

Для большинства задач используется единый стандарт компиляции.

### Стандартная компиляция
Для файлов внутри папки `src` каждого проекта используйте следующую команду:

```bash
gcc -Wall -Wextra -Werror -std=c11 src/filename.c -o filename -lm
